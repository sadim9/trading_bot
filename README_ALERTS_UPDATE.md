## 🎓 WHAT TO LOOK FOR

### Ideal Entry Setup:
1. **Dashboard shows:** Session ACTIVE, ATR OK, ST BULLISH (or BEARISH for shorts)
2. **Chart shows:** Price near orange line (EMA 50), distance <1%
3. **RSI shows:** Above 50 for long, below 50 for short
4. **Arrow appears:** Green (BUY) or Red (SELL)
5. **Notification pops:** Shows full entry/SL/TP details
6. **R:R Ratio:** Should be at least 1:1, ideally 1:2+

### Decision at Alert:
```
IF R:R Ratio ≥ 1:1 → Take the trade
IF R:R Ratio < 1:1 → Skip, wait for next signal
```

## 🆘 IF SOMETHING DOESN'T WORK

### No visual arrows appearing:
→ Verify you're in trading hours (08:00-21:00 UTC)  
→ Enable "Enable London Session" or "Enable NY Session" in inputs  
→ Run the backtest to see if signals generate  

### No notifications arriving:
→ Confirm alert was created (check Alerts panel)  
→ Try creating a test alert on "Outside Trading Hours"  
→ Check TradingView app is running  
→ For email: verify not in spam folder  
→ For Discord: test webhook URL separately  

### Position size is 0 or very small:
→ Check "Risk per Trade" is at least 1%  
→ Verify "Pip Size" matches your symbol (EURUSD=0.0001, GOLD=0.01)  
→ Increase initial capital input if needed  

### Too many/too few signals:
→ Increase SuperTrend Period (fewer signals) or decrease (more signals)  
→ Adjust Pullback % threshold  
→ Enable/disable Market Structure Filter  
→ Run new backtest to find optimal parameters  

→ **See ALERTS_AND_NOTIFICATIONS_SETUP.md for full troubleshooting**
